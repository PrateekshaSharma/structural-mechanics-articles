# Fracture-Mechanics-Brittle-vs.-Ductile-Materials

This repository contains the LaTeX source and compiled PDF for the article:

This article compares fracture mechanisms in brittle and ductile materials. It discusses energy-based fracture criteria, stress intensity factors, plastic zone effects, stress triaxiality, and microstructural influences. The study highlights the contrasting behaviors of brittle and ductile fractures, with implications for accurate failure prediction in engineering applications.
