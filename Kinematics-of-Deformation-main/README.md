# Kinematics-of-Deformation

This repository contains the LaTeX source and compiled PDF for the article:

This article presents the kinematics of deformation for continuous media, covering motion mappings, displacement fields, the deformation gradient, strain measures in both small and finite deformation regimes, polar decomposition, and rate kinematics. Illustrative examples (uniaxial stretch and simple shear) connect abstract tensor definitions to physical deformation.
